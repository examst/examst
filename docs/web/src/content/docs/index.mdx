## Quick Example

<TypstExample code={`#question(points: 10)[
    What is the airspeed velocity of an unladen swallow?
    #multi-choice(
      marker: "bubble-letter",
      [European or African?],
      correct[About 11 m/s],
      [Unknown],
    )
  ]

  #question(points: 5)[
    The capital of France is #fill-in[Paris].
  ]`} preamble={`#examst-set(render-question-counter: it => numbering("1.", it.get().last()))`} width="400pt" />
